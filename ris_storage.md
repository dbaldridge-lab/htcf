# RIS Storage
The lab additionally stores some office documents and miscellaneous data files on RIS. Use the instructions below if you need to access this storage.

## Connect to the network
First things first is to connect to WUSM-secure wifi or ethernet. While working off campus, you need to use a VPN to access any files stored on RIS. 

Note: This is not required for logging into HTCF. 

### VPN
If off campus, you will need to Download Cisco Anyconnect and use a VPN to connect. 
[Connect to the Network through VPN \| Arts & Sciences IT](https://it.artsci.wustl.edu/connect-network-through-vpn)

Connecting address is `msvpn.wusm.wustl.edu`. Use your wustl key and password for authentication.

### New lab member instructions
We will first need to request RIS access for the new account.

### Mac Instructions
Connect to dbaldri storage on RIS:
1. Go to the Finder application.
2. Click Go in the top menu bar
3. Choose “Connect to Server” near the bottom of the list.
4. Copy and paste the Server Address: smb://storage1.ris.wustl.edu/dbaldri
5. Click the Plus sign so that it is added to your Favorites.
6. Click Connect.

## Windows Instructions
Connect to dbaldri storage on RIS:
1. Open **File Explorer**.
2. In the left sidebar, click **This PC**.
3. At the top, click the **three dots** menu or **Computer** tab, then choose **Map network drive**.
4. Choose a drive letter if prompted.
5. In the **Folder** field, enter:`\\storage1.ris.wustl.edu\dbaldri`
6. Check **Reconnect at sign-in** if you want it saved for future use.
7. Click **Finish**.
8. When prompted, sign in with your **WUSTL Key** credentials.
9. The storage should then appear in File Explorer under **This PC**.
